- [2026-10-22] Живая проверка выявила баг: в рантайме OpenCode `process.execPath` — это сам `opencode-cli.exe`, поэтому `execFile(process.execPath, [eslint.js, ...])` запускал OpenCode CLI (`CliError/ShowHelp`), а ошибка молча проглатывалась. Исправлено: функция `nodeBinary()` берёт `execPath` только если это Node, иначе `node` из PATH; ошибки линтера теперь пишутся в лог через `console.warn`. Добавлены 2 теста на выбор бинарника.

# my-opencode-project

## Как агент работает в проекте
- **Читаемые инструкции**: Корневой каталог `AGENTS.md` (правила безопасности и рабочий процесс), `rules.md` (жёсткие правила проекта) и файлы навыков в `.opencode/skills/`.
- **Права доступа**: Настроены в `opencode.json`, запрет на доступ к `.env`, операции с файлами требуют подтверждения или разрешены только для безопасных команд.
- **Проверки безопасности**: Ограничение путей (блокировка `.env`), автоматическая проверка линтером, поддержка памяти через `docs/memory.md`.
- **Запуск тестов**: Использование навыка `run-tests` или ручной запуск `npm test`.

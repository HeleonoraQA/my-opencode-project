# Инструкции
1. Навык вызывается только вручную командой/инструкцией пользователя, когда нужно запустить тесты.
2. Выполнить команду `npm test` (или соответствующую команду тестирования).
3. Проверить код выхода.
4. Если тесты не прошли, проанализировать вывод и попытаться исправить код.

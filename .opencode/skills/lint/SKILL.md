# Инструкции
1. Выполнить команду `npm run lint`.
2. Если есть исправимые ошибки, выполнить `npm run lint -- --fix`.
3. Убедиться, что после исправления повторная проверка проходит.
4. Навык запускается автоматически через хук `pre-commit`.

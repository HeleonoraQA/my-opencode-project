# Правила проекта

Жёсткие правила для агента и контрибьюторов. Дополняют `AGENTS.md`.

## Доступ к файлам
- `.env` и `.env.*` — **полный запрет** на чтение и изменение.
  Задаётся в `opencode.json` (`read`/`edit` → `deny`), обойти нельзя.
- Не изменять файлы за пределами проекта без явной необходимости.
- Никогда не коммитить секреты, ключи, `node_modules/` и артефакты сборки.

## Права shell
- Без подтверждения разрешены только: `git *`, `npm test`, `ls *`.
- Любая другая команда требует подтверждения (`ask`).

## Изменения и проверки
- Правка файлов (`edit`/`write`/`patch`) требует подтверждения.
- Перед коммитом запускаются `npm run lint` и `npm test` (husky `pre-commit`).
- Перед push запускаются `npm run lint` и `npm test` (husky `pre-push`).
- Сообщения коммитов — Conventional Commits: `type(scope): summary`
  (`feat`, `fix`, `docs`, `chore`, `refactor`, `test`, `ci`, `build`, `perf`, `style`).

## Документация
- Меняя правила, права или структуру проекта, обновлять `AGENTS.md` и `docs/memory.md`.
